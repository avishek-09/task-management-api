# Task Management API

A simple Restful Task Management API built with C# and ASP.NET Core. 
This Project was cerated to practice .NET backend development, REST APIs, Entity Framework Core, databse operations, and basic API validation.

## Features
- Create Task 
- View all task 
- View a task by its ID
- Update, Delete task 
- Request Validaition 
- SQLite database persistence
- Swagger UI
- Automatic task Creation timestamp

## Technologies Used
- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Swagger / OpenAPI
